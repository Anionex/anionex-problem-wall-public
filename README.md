# Anionex — published research questions

Public snapshots from [anionex.me/problems](https://anionex.me/problems).

Only deliberately selected versions are published here. Private drafts and unpublished history are kept in a separate private repository. Each preserved version retains its exact original Markdown bytes and any corresponding OpenTimestamps receipts. A pending receipt is not yet a verified Bitcoin timestamp.

Hiding a question on the website does not retract files or Git history that were already public. No research questions have been published yet.
